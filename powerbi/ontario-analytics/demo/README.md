# Synthetic browser companion

Open `index.html` directly, or use the portfolio demo link. All numerical values and PHU/health-region labels are invented deterministically for this presentation; they are not anonymized or perturbed publisher observations. They were generated independently of the real source values. The demo covers eight illustrative indicators, 29 invented PHUs, three procedures and six invented regions to exercise the existing report interaction design. This smaller procedure menu does not alter the complete native report or private source files.

`synthetic-data.json` records the same values embedded in the self-contained HTML. Its code performs no API calls and persists no visitor data. Periods mirror the historical report's example ranges for interface testing only. All preview images are generated from this synthetic dataset and labelled accordingly. Do not cite demo values as research findings.
